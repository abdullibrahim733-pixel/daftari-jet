The repo is a single Next.js 16 application (app router) whose runtime server code, shared libraries, CLI scripts, tests, and agent skill definitions live side-by-side at the workspace root. `scripts/` provides Node ESM entry points (`migrate`, `seed`, `reset-db`, `run-jobs`) invoked via npm scripts that all go through `scripts/register-alias.mjs` to resolve TypeScript paths; `tests/` reuses that same alias loader so integration tests run against a real SQLite database under the same type system as production code; `agent_skills/` supplies structured guidance for coding agents working inside this repo. Cross-cutting wiring is centralized in `package.json` scripts, `next.config.ts`, `tsconfig.json`, and `eslint.config.mjs`, while deployment targets Vercel (`vercel.json`). The PRD defines the product surface (voice → proposal → human confirmation → confirmed ledger) and `architecture.md` defines the implementation shape; children implement those contracts rather than each other directly.
