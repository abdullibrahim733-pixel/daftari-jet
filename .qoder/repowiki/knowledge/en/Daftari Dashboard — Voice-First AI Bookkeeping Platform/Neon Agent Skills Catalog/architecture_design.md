This module is a flat catalog of agent skills under `.agents/skills/`, each skill being a directory containing a `SKILL.md` front-matter document (YAML header with `name`, `description`, optional `parent`/`metadata`) plus an optional `references/` subdirectory for linked reference docs. The top-level `neon` skill acts as the root overview and dispatcher, while `neon-postgres` declares itself as a child via the `parent: neon` metadata field; both point back to the upstream `neondatabase/agent-skills` repo in their `metadata.source`. There is no executable code — the module's structure is purely documentation consumed by the agent runtime to select the right skill based on user intent.
