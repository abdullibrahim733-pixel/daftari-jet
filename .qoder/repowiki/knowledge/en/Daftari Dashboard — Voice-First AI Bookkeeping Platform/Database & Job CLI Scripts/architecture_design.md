Flat collection of independent top-level scripts, each a self-contained Node ESM entry point that boots a `Db` via `@/server/db/client`, performs one operation, then calls `closeDatabase()`. They import production server modules (`@/server/db/migrations`, `@/server/repositories/*`, `@/server/services/jobs`) rather than duplicating logic. `register-alias.mjs` is a shared bootstrap loaded before any script: it uses `node:module.registerHooks` to resolve the `@/` path alias (and bundler-style extensionless relative imports) against `src/`, allowing these scripts to run without Vite/Vitest bindings. Script behavior branches on environment variables — `DAFTARI_RESET_CONFIRM` gates destructive PostgreSQL resets, `DAFTARI_SEED_*` overrides seed defaults, `DATABASE_URL`/`NEON_DATABASE_URL` select SQLite vs PostgreSQL paths in `reset-db.ts`. Each file documents its npm script target in a JSDoc header comment.
