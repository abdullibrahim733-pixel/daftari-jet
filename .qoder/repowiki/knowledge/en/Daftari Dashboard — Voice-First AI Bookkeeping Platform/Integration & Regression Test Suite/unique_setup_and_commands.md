Tests require the project's TypeScript path aliases (`@/server/*`) to resolve, so they must be run from the repository root with the same tsconfig/module resolution as the app. Each process creates its own temp SQLite file under `tmpdir()` plus a per-PID media root under `<cwd>/.daftari-test/media-<pid>-<uuid>`; these directories are removed by a global `after` hook after the suite finishes.
